# Project: SENSORITY

Публичный репозиторий лендинга SENSORITY на React + Vite. Публикация настроена через GitHub Actions: workflow из `.github/workflows/pages.yml` собирает проект в `dist/` и передаёт готовый сайт в GitHub Pages.

## Включить / проверить публикацию

1. Открой **Settings → Pages** в этом репозитории: https://github.com/KrostyMall/Landing-SENSORITY/settings/pages
2. В разделе **Build and deployment** установи **Source: GitHub Actions**.
3. Открой вкладку **Actions** и дождись успешного завершения процесса **Build and deploy SENSORITY to GitHub Pages**.
4. После первого успешного деплоя GitHub покажет публичный адрес в Settings → Pages.

При каждом изменении ветки `main` сборка и публикация запускаются автоматически. Vite настроен на относительные пути, чтобы скрипты, стили, шрифты и изображения загружались из адреса проекта GitHub Pages.

## Локальная разработка

Требуется Node.js 20+:

```bash
npm ci
npm run dev
```

Production-сборка:

```bash
npm run build
```

Готовые статические файлы появятся в `dist/`. Не открывай корневой `index.html` двойным кликом: это исходная страница для Vite, а не собранный сайт.

## Ограничения

- Репозиторий публичный, поэтому исходники доступны для скачивания. Удаление кнопки «Архив» не может запретить это.
- GitHub Pages хостит статический сайт; постоянный локальный сервер не нужен, но 100% бесперебойную работу хостинга гарантировать нельзя.
- Форма «Оставить почту» сейчас демонстрационная: адрес сохраняется только в localStorage этого браузера и не отправляется на сервер. Для реальных заявок понадобится внешняя форма или сервер.
- Не добавляй пароли, API-ключи и приватные данные в репозиторий.
