# Project: SENSORITY

Адаптивный лендинг на React + Vite для GitHub Pages.

- **На компьютере и широких окнах:** прежняя широкая двухколоночная версия.
- **На телефоне:** вертикальная версия с видимой 3D-сценой и прокруткой страницы.
- **Публичный адрес:** https://krostymall.github.io/Landing-SENSORITY/

## Как публикуется сайт

GitHub Pages в этом репозитории публикует корень ветки `main`. Поэтому `index.html` и папка `assets/` в корне — это автоматически сгенерированная production-сборка, не редактируй их вручную.

Редактируемый вход Vite находится в `source.html`; компоненты — в `src/`, статические исходные материалы — в `public/`. При изменении исходников workflow из `.github/workflows/pages.yml` выполняет `npm ci` и `npm run build`, копирует собранный HTML/CSS/JS в корень репозитория и отправляет коммит. GitHub Pages затем публикует эту версию.

Настройка GitHub Pages должна быть **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)**. Именно этот режим соответствует текущей публикации репозитория.

## Локальная разработка

Требуется Node.js 20+:

```bash
npm ci
npm run dev
```

Открой **http://localhost:8080/source.html** — это исходная Vite-страница для разработки. Корневой `index.html` предназначен для публикации GitHub Pages.

Собрать production-версию вручную:

```bash
npm run build
```

Vite создаст готовые файлы в `dist/`.

## Ограничения

- Репозиторий публичный, поэтому исходники доступны для скачивания. Удаление кнопки «Архив» не может запретить это.
- GitHub Pages не требует постоянно работающего компьютера, но 100% бесперебойную доступность хостинга гарантировать нельзя.
- Форма «Оставить почту» пока демонстрационная: адрес сохраняется только в localStorage текущего браузера и не отправляется на сервер. Для реальных заявок нужен сервер или сервис обработки форм.
- Не добавляй пароли, API-ключи и другие приватные данные в репозиторий.
