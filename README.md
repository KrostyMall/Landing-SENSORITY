# Project: SENSORITY

Статический лендинг на React + Vite. Настроена автоматическая публикация в GitHub Pages через GitHub Actions.

## Опубликовать на GitHub Pages

1. Создай на GitHub новый **Public**-репозиторий, например `project-sensority`. Не добавляй заранее README, лицензию или `.gitignore`, если загружаешь этот проект целиком.
2. Распакуй этот архив и загрузи **содержимое папки `project-sensority`** в корень репозитория. В корне должны находиться `package.json`, `vite.config.ts`, `index.html`, папки `src/`, `public/` и `.github/`.
3. На GitHub открой репозиторий → **Settings → Pages**. В разделе **Build and deployment** выбери **Source: GitHub Actions**.
4. Открой вкладку **Actions**. Рабочий процесс `Build and deploy SENSORITY to GitHub Pages` автоматически соберёт и опубликует сайт после push в ветку `main`. Если спросит разрешение на запуск workflow, подтверди.
5. Когда workflow завершится зелёным статусом, зайди в **Settings → Pages** или в результат workflow — там будет ссылка вида `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

При каждом следующем push в `main` сайт будет автоматически обновляться. Базовый путь ресурсов настроен относительно, поэтому сборка поддерживает адрес GitHub Pages с именем репозитория в URL.

## Важно знать

- GitHub Pages размещает **публичный сайт**. На бесплатном GitHub для этого проекта используй публичный репозиторий. Опубликованная страница доступна любому человеку с интернетом.
- Спрятанная/удалённая кнопка «Архив» не защищает исходники сайта: браузер должен загружать JavaScript, CSS, изображения и шрифты, а содержимое публичного репозитория также можно скачать. Не добавляй в репозиторий пароли, API-ключи или приватные данные.
- Форма почты в текущем прототипе **не отправляет адрес на сервер**: она сохраняет его только в localStorage этого браузера/устройства. Для сбора реальных заявок понадобится внешняя форма или сервер.
- GitHub Pages рассчитан на статические сайты. Здесь приложение работает как статический сайт, отдельный постоянно запущенный сервер не требуется. Абсолютную доступность 100% любой хостинг гарантировать не может.

## Локальная разработка

Требуется Node.js 20+:

```bash
npm ci
npm run dev
```

Для сборки:

```bash
npm run build
```

Готовые файлы появятся в `dist/`. Не открывай корневой `index.html` двойным кликом: это вход для Vite, а не собранная версия сайта.
